# Signed archive privacy and provenance audit

Checked 2026-10-23 against the successfully validated distribution archive for version 1.0 (1). Deep strict code-signature verification passed. The exported IPA hash is recorded in `setup-status.json`.

The main privacy manifest declares no tracking and Gameplay Content, User ID and Purchase History linked for app functionality. All three extension manifests declare no independently collected data and no tracking. These responses were explicitly approved by the owner and published in App Store Connect; see `privacy-published.jpg`.

The archive contains no AppLovin framework, TelemetryDeck binary/resource bundle or other embedded third-party runtime framework. Their SPM references remain registered in the project but are not linked into the shipping app. No advertising/analytics initialization or tracking prompt is active. Apple services handle optional purchases, cloud saves, leaderboards and hosted content. Required-reason declarations remain in the manifest; review them again whenever accessed APIs change.

Core visuals use project SwiftUI/Canvas drawing, system typography and SF Symbols. The only bundled image source in the app is its project AppIcon; there is no bundled third-party music, custom font or provider puzzle feed. Puzzles are generated by the project's offline tooling. Swift Snapshot Testing is a test dependency and SwiftLint is tooling. Re-audit any subsequently added media or SDK before release. This inventory does not claim physical-device behavior has been tested.
