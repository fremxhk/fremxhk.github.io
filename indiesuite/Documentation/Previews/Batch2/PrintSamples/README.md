# RecallGlass native print samples

Unmodified PDFs generated by the app print engine in the passing sequential suite. All 28 pages across these twelve files were rendered and visually reviewed. These are print-output samples, separate from app UI screenshots.

The single-card speech samples use 0.85× type. Eight-card pagination fixtures use 1.0× type and reversed speaking order; all six paper/card combinations were also tested at 0.85×, 1.0× and 1.35×. Oversized body and footer text must fail export without clipping. Native 72-point-per-inch dimensions are preserved. Print at 100% / actual size; physical-printer verification remains open.
