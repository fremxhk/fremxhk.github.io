## Scope

Simulator jobs run sequentially, without parallel testing or simulator clones. Native iPhone and iPad workflow captures are identified by profile in their evidence paths. The five-app Release workflows run complete thirteen-method cohorts and the original three-app workflows run complete fifteen-method cohorts per device on the unlocked host after other heavy jobs were paused. Failed, partial and pre-correction result bundles are excluded. Profile repetitions do not add methods. Workflow, accessibility and purchase UI use iOS 27.2; core, evaluations and offline storage use the separate iOS 27.0 minimum-OS fixture. Local StoreKit tests verify configured transactions and entitlement behavior; they are distinct from live App Store purchase execution. The original three-app workflow fixtures and five-app Release workflows are described separately in [ConsumerValidation.md](ConsumerValidation.md).

Production CloudKit service and process-isolated synchronization checks are separate SDK-client checks, not XCTest methods; see [ProductionMirroringResults.md](ProductionMirroringResults.md). Distribution archive, entitlement, privacy-manifest, processing and screenshot-delivery verification are reported separately.
