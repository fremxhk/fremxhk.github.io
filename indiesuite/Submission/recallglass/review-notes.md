# RecallGlass — App Review information

Preparation for version 1.0.0. No developer registration or login is required.

1. **Demonstration:** No app account is required. Use the built-in synthetic example from the main capture or creation flow, then review the saved result and available exports. The example uses the same review screens as user-provided content.
2. **Purpose and audience:** Create study cards and printable speaker cues from material you provide. Intended audience: Students, independent learners and speakers preparing their own study sessions and presentations. General-public distribution, not a private employee-only app.
3. **Access and setup:** For Academic mode choose Create study deck, Use an example and Create cards; open a card, type an answer, reveal it and select a grade. For speech mode use its synthetic example, review the cues, start/pause/reset the timer and preview printable cutouts. Choose paper/card sizes before sharing the PDF or using the native print sheet. Five completed AI actions are free; Pro enables additional actions. No external sample file or login credentials are required.
4. **External services:** Apple StoreKit/App Store for purchases; optional private CloudKit storage; SwiftData, PDFKit, Vision and Foundation Models for supported local data, OCR and generation. Apple AVFoundation and Speech for consented recording and on-device transcription. No developer-operated backend, third-party AI API, external tax/health/VIN/price data service, ad SDK or developer analytics endpoint is used.
5. **Regions:** English interface. The app and paid products are configured for USA availability for this submission. Apple determines purchase/trial eligibility and supported on-device model and speech language/region availability. iCloud and system permissions depend on the user account and platform. No separate regional service is supplied.
6. **Rights and regulated activity:** Generated cards and feedback can be incomplete; verify them against the source. The learner chooses the final grade. Print cutouts at actual size and check printer margins. Speech import and recording require consent and supported English (U.S.) on-device recognition. Pasted text remains available when speech is unavailable. The app does not provide third-party study content. Users provide their own material; synthetic examples are generated locally. No regulated professional service, professional credential, certification or protected third-party content license is claimed. There are no app accounts or public user-content feeds.
